## درباره پروژه

زرین‌پال آنالیتیکس یک داشبورد تحلیلی مبتنی بر هوش مصنوعی است که از روی **۲.۲ میلیون تراکنش واقعی** پرداخت، بینش‌های قابل اجرا برای پذیرندگان تولید می‌کند. این پروژه برای چالش زرین‌پال ساخته شده و هدف آن کمک به پذیرندگان برای درک الگوهای پرداخت، بهبود نرخ موفقیت تراکنش‌ها و کاهش درآمد از دست رفته است.

## امکانات

### 📊 داشبورد اصلی
- نمای KPI با نرخ موفقیت، تعداد تراکنش، مبلغ کل و درآمد از دست رفته
- نمودارهای تعاملی مقایسه PSPها، بانک‌ها و الگوهای ساعتی
- قابلیت ردیابی (Traceability) — روی هر عدد کلیک کنید تا فرمول و کوئری SQL نمایش داده شود

### 💡 بینش‌های هوشمند
- تحلیل فرضیه‌محور با توصیه اقدام مشخص
- هر بینش شامل: فرضیه، شواهد داده‌ای، و اقدام پیشنهادی
- قابلیت گسترش جزئیات برای مشاهده فرمول و SQL

### 🤖 دستیار هوش مصنوعی
- چت با هوش مصنوعی برای تحلیل داده‌های پرداخت
- ۱۱ ابزار تحلیلی (آمار کلی، PSP، بانک، پذیرندگان، الگوی تلاش مجدد، و...)
- اجرای کوئری SQL سفارشی توسط هوش مصنوعی
- ردیابی منابع داده استفاده شده در هر پاسخ

### 🏪 تحلیل پذیرندگان
- رتبه‌بندی پذیرندگان بر حجم تراکنش
- نمودار درآمد از دست رفته به تفکیک پذیرنده
- جزئیات عملکرد هر پذیرنده

### 🏦 تحلیل PSP
- مقایسه نرخ موفقیت ارائه‌دهندگان خدمات پرداخت
- ماتریس بانک × PSP
- تحلیل بر حسب مبلغ و ساعت روز

## شروع

### پیش‌نیازها

- Node.js 20 یا بالاتر
- npm
- کلید API AvalAI (یا OpenAI)
- فایل CSV دیتاست چالش

### نصب

```bash
git clone https://github.com/Hedyeh26/Zarinpal-Challenge.git
cd Zarinpal-Challenge
npm install
```

### پیکربندی

```bash
cp .env.example .env.local
```

فایل `.env.local` را ویرایش کنید و کلید API خود را قرار دهید:

```
OPENAI_API_KEY=your-avalai-api-key-here
```

### واردکردن داده

فایل CSV دیتاست چالش را در پوشه `data/` قرار دهید:

```bash
# فایل باید به این مسیر باشد:
# data/other_challenge_data.csv

npm run db:import
```

### اجرا

```bash
npm run dev
```

برنامه در `http://localhost:3000` اجرا می‌شود.

## تکنولوژی

| لایه | فناوری |
|------|--------|
| فرانت‌اند | Next.js 15, React 19, TypeScript |
| استایل‌دهی | Tailwind CSS, shadcn/ui |
| نمودارها | Recharts |
| هوش مصنوعی | Vercel AI SDK, GPT-4o (AvalAI) |
| پایگاه داده | SQLite (better-sqlite3) |
| RTL | وزیرمتن (Vazirmatn) فونت |

## عملکرد

- **پاسخگویی هوش مصنوعی**: زیر ۵ ثانیه با استفاده از کشینگ
- **بارگذاری صفحات**: زیر ۱ ثانیه
- **پشتیبانی موبایل**: ریسپانسیو کامل
- **RTL**: پشتیبانی کامل از راست به چپ

## ساختار داده

دیتاست شامل ۲.۲ میلیون رکورد تراکنش با فیلدهای:

| فیلد | توضیح |
|------|--------|
| `adjusted_amount` | مبلغ تراکنش (ریال) |
| `try_status` | وضعیت تلاش (Verified, Failed, InBank, etc.) |
| `try_seq` | شماره تلاش (0, 1, 2...) |
| `psp` | ارائه‌دهنده خدمات پرداخت |
| `bank_name` | نام بانک صادرکننده |
| `hour` | ساعت تراکنش |
| `date` | تاریخ تراکنش |
